# Flask Employee Management System (EMS)

An AI-driven SDLC automated web application built with Flask and SQLite, managed via CodeMie agentic workflows, Jira integration, and Human-in-the-Loop (HITL) governance.

## Key Features & Enhancements
- **Delete Employee:** Remove records with instant DB cleanup and redirect.
- **Edit Employee:** Update role, department, and compensation with validation checks.
- **Search & Filter:** Real-time search by employee name and department filtering.

## Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite
- **Testing:** Pytest (Automated Unit & Integration), Gherkin Acceptance Scenarios
- **Automation / Orchestration:** CodeMie AI Workflows (BA, Solution Architect, Dev, QA, Jira Closure)
